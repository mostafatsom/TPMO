# TPMO v1.0.0

Initial public release of TPMO — Two-Phase Metamodel-Driven Optimization.

## Included

- Latin Hypercube initial sampling
- XGBoost response metamodels
- Extensive Constraints
- adaptive expensive sampling
- upstream FSGO GLOBAL/LOCAL search
- Phase-I inactive-variable discovery
- Phase-II reduced-space refinement
- generic Python problem interface
- examples, tests, comparison script, and citation metadata

## Not included

The structural case studies used in the associated paper are intentionally excluded from this repository.
